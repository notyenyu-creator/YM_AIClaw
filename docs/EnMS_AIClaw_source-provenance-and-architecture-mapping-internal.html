比對方法

比對方法與證據版本

本次比對重點是 DenchClaw 到 EnClaw 的差異，使用可重跑的 Git 紀錄與行數歸因，而不是用主觀估算。

1. 比對基準

origin/main...HEAD，用於追蹤從 DenchClaw fork 出來的起點，到目前 EnClaw 分支之間的差異。

2. 模組範圍

只納入指定四類統計模組，不納入整份程式碼庫，也不納入無關 UI / docs。

3. 歸因規則

新增檔案計入 EnClaw 新增 / 整合；修改檔案中 DenchClaw 原本保留的行數計入 DenchClaw 原始碼，新增行數計入 EnClaw 新增 / 整合。

4. 排除測試

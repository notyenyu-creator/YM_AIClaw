# EnMS Efficiency Improvement Playbook

## Goal
把能效分析輸出成可執行改善清單。

## Query Pattern
1. 先比較 summary KPI
2. 找出低功因 / 高需量 / 高耗能群
3. 補場域與公司語意
4. 若帳單與費率可用，再補 `TaipowerBills / PowerAccounts / ElectricityPricePlans / ElectricityPriceRates`
5. 把建議拆成 quick win、排程調整、設備投資三層，不要把所有節能機會混成一類

## Output Contract
- 問題摘要
- 改善優先順序
- 追蹤建議

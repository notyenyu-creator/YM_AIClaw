# ERP Feature Guide

> 適用範圍：ERP phase-1 唯讀分析
> 更新日期：2026-05-04

## 1. 這份文件的用途

這份 guide 不是 schema 說明書，而是給 agent 快速判斷：

- 目前 ERP skill 能做什麼
- 哪些題目應該交給 ERP
- 哪些題目要轉交其他系統

---

## 2. 目前優先支援的能力

### 訂單

- 銷售訂單摘要
- 未出貨訂單查詢
- 交期延誤分析
- 訂單明細 drill-down

### 採購

- 採購單狀態
- 未收貨採購單
- 供應商採購摘要

### 庫存

- 可用庫存快照
- 高低庫存排行
- 品項 on-hand / available / reserved 分析

### 出貨

- 出貨單狀態
- 揀貨 / 出貨進度
- tracking / shipping_status 摘要

### 生產 / 工單

- 工單狀態
- 在製進度
- 與 BOM 相關的基礎關聯查詢

### 財務文件

- 應收 / 應付摘要
- 發票 / 請款單狀態

---

## 3. 不應由 ERP 單獨回答的題目

以下題目不應直接只靠 ERP：

- 客戶互動背景
- 商機脈絡
- LINE 對話紀錄
- 倉位事件細節
- RFID 事件流
- EMS 能耗明細

遇到這些題目時：

- `Y-CRM` 提供商業背景
- `WMS` 提供倉位 / 批次事件
- `MES` 提供工單現場真相
- `RFID` 提供事件追蹤
- `EMS` 提供能耗真相

---

## 4. 圖表規則

ERP 圖表只能在以下條件下使用：

1. 已先拿到真實聚合資料
2. 聚合結果非空
3. 圖表只是輔助，不取代文字摘要

若資料不足：

- 不畫圖
- 回純文字 summary

---

## 5. phase-1 邊界

目前 phase-1 只做：

- 唯讀查詢
- summary
- compact chart support
- planner/context pack

目前 phase-1 不做：

- 高風險寫入
- 單據建立
- 自動核准
- 財務異動

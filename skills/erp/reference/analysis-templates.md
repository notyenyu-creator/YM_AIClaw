# ERP Analysis Templates

> 更新日期：2026-05-04

## 1. 訂單摘要模板

適用：

- 本月未出貨訂單
- 指定客戶的訂單狀態
- 交期延誤摘要

輸出建議：

1. 範圍與 scope
2. 訂單件數 / 總金額
3. 狀態分布
4. 風險單據
5. 下一步建議

---

## 2. 庫存快照模板

適用：

- 可用庫存排行
- 指定品項庫存
- 缺料風險

輸出建議：

1. 查詢範圍
2. on-hand / available / reserved
3. 低庫存 / 高庫存重點
4. 是否需要轉 WMS / MES

---

## 3. 出貨進度模板

適用：

- 未出貨 / 部分出貨
- 揀貨、出貨、追蹤號狀態

輸出建議：

1. 單據範圍
2. 出貨狀態分布
3. 延誤或卡關原因
4. 是否需要 WMS handoff

---

## 4. 圖表模板

圖表只能在以下情況產生：

1. 已有非空聚合資料
2. 類別維度清楚
3. 只作為補充視覺

常見圖：

- 訂單狀態件數長條圖
- 出貨狀態圓餅圖
- 庫存排名長條圖

若資料不足：

- 改回文字摘要
- 不產生空圖
